# Kiln — Website

Marketing, Privacy Policy, and Support pages for the **Kiln** app
(a 100% on-device AI meeting assistant for Mac and iPhone), served via
**GitHub Pages**.

| Page | File | URL (once Pages is enabled) |
| :-- | :-- | :-- |
| Home | `index.html` | `https://guptatushar10397.github.io/kiln-site/` |
| Privacy Policy | `privacy.html` | `https://guptatushar10397.github.io/kiln-site/privacy.html` |
| Support | `support.html` | `https://guptatushar10397.github.io/kiln-site/support.html` |

Styling is in `style.css`. `.nojekyll` disables Jekyll so files are served as-is.

This is a **public** repo (GitHub Pages on the free plan only serves public
repos). It contains **no app source code** — only these static pages.
